How it works

  • The system will find all active drivers with payment records for the selected week
  • Invoices will be created in DRAFT status for review and editing
  • If an invoice already exists for a driver and week, it will be skipped
  • Each invoice includes all daily payments, extras, deductions, and van charges
  • After generation, review the invoices, approve them, and send them via email
